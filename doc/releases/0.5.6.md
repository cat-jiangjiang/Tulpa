# Tulpa 0.5.6

本版整合已合并的 main 改动与 dev 的 #16，并发布 Windows MCP 轻量版和 Linux 终端源码包。本次不发布 Windows 完整版，其最新下载仍为 0.5.5。两份小鲸鱼人物卡保持原内容；各平台共用 MCP 聊天与授权实现。

## 下载

- `Tulpa-MCP-0.5.6-win-x64.zip`：Windows MCP 轻量版，使用系统 WebView2，语音模型按需安装。
- `Tulpa-0.5.6-linux.tar.gz`：Linux x86_64 / ARM64 终端源码包，包含 CLI、TUI、MCP 与可选内置模型。需要 Python 3.13 或 uv；首次运行 `./tulpa` 联网安装依赖。
- `SHA256SUMS.txt`：两个发行包及 FFmpeg 源码归档的校验值。
- `FFmpeg-b08d7969c5-source.tar.gz`：随 Windows 包提供的 FFmpeg 对应源码。

## 改进

- **Linux 支持（#8）**：终端界面、多实例、MCP 授权、SL 本地及 Docker 接入、按需组件与原生数据读取适配。QQ、微信、SnowLuma、Docker 镜像及登录数据不随包分发。
- **会话授权（#12、#16）**：先按平台筛选再分页；切换平台不残留旧 OneBot 列表。统一选择已导入会话、当前 QQ 群或当前 QQ 好友，支持名称与号码搜索；实时群和私聊无需先导入历史。
- **连接与账号（#11、#14）**：保留微信账号发现中的磁盘根路径；写入本机 Codex 配置时可修改 MCP 名称，避免已有同名连接冲突。
- **聊天材料（dev #16）**：等待、补读和恢复共用图片、引用及转发材料交付；具备图片读取权限时直接返回实际图像，按内容与授权范围复用。下载、数量与响应体均有上限；未获授权的图片不会借复用跨范围访问。
- **学习与回复衔接（dev #16）**：学习阶段提交保留完成回执，并将新消息交回聊天流程。压缩重复的辅助上下文，保留消息正文、读取水位及重规划要求；增加仅含时序和状态的本地诊断。
- **CI 与兼容性**：修复 Windows 规范路径比较、清空测试环境时误删系统 TLS 变量、测试对可选终端界面的依赖。两平台回归纳入新增材料交付、图片复用和会话筛选检查。
- **Linux MCP 重启**：处理关闭长连接后的端口回收，避免立即重启误报占用；已有活动监听仍不能被另一实例接管。发行归档固定 Linux 启动脚本的 LF 换行和可执行权限。

本次不合并尚待评审的 #5、#13、#15、#17、#18。

## 升级

Windows 按 [保留数据升级](../UPGRADE.md) 更新同一版本类型；Linux 按 [Linux 升级说明](../LINUX_UPGRADE.md)。先停止群聊和后台，备份数据及自行修改的人格。不要将全新包直接覆盖私人数据目录，也不要将 Windows 和 Linux 的运行时混用。

已有聊天、学习库、授权和人格无需重建。图片身份索引对新导入消息增量维护；旧历史的索引回填是可选的显式操作，不会在升级时扫描全库。升级后重连 MCP、刷新工具；需要采用新通用提示的聊天会话应重新开启。

## 验证边界

发布门槛为 Windows 开发与随包运行时回归、真实 Edge 界面夹具和 EXE 启动，以及 Linux 隔离回归、终端启动与发行包检查。GitHub Actions 分别运行 Windows、Linux x86_64 和 ARM64；实际结果与来源提交见 [本版 Release](https://github.com/fumingyang2004/Tulpa/releases/tag/v0.5.6)。包内 `build-manifest.json` 记录版本、来源提交和文件哈希。

本次验收不向真实 QQ 群发送消息、不调用付费模型，也不以 mock 证明真实账号取钥、扫码、所有发行版兼容或学习质量。Linux 本机测试使用 WSL2 / Ubuntu x86_64，ARM64 依靠 CI；此前贡献者的真实环境记录保留在 Linux 文档中。外部 Agent 仍负责持续推理，Tulpa 不会自行启动新模型。
